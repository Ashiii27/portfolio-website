## Introduction

Android APK analysis is a critical skill for mobile security engineers and malware analysts...

## Static Analysis with Jadx

First, decompile the APK using Jadx to inspect the Java source...

```bash
jadx -d output/ suspicious.apk
```

## Dynamic Analysis with Frida

Hook into runtime method calls to observe behavior:

```js
Java.perform(() => {
  const Activity = Java.use("android.app.Activity");
  Activity.onCreate.overload("android.os.Bundle").implementation = function (bundle) {
    console.log("[*] onCreate called");
    this.onCreate(bundle);
  };
});
```

## Conclusion

Combining static and dynamic analysis gives a comprehensive picture of APK behavior.
